# Anonymous-review packaging note

This review repository was assembled from the finalized CSRA v0.8 R4/A2 analysis artifacts. Identity-bearing protocol approval documents/records and private execution metadata are intentionally omitted for double-blind review. The omitted files are cryptographically bound to the study lineage through hashes recorded in the retained lock/audit materials and will be included in the permanent public release after peer review.

No earlier v0.6 reserve-study result files are included in this package.
