The later figure generator reads the underlying values rather than the earlier rounded plotting constants. PDF bytes are not the numerical acceptance criterion. References are supplied under `paper/reference/figures/` for visual comparison.

The default route also rebuilds full-precision post hoc result CSVs: 48 pooled contrasts, 144 target-specific intervals, 144 omitted-target intervals, group-influence/error strata and expanded factorial outcomes. The article selects a subset. `new_analysis/revision_20261027/REPORT.md` describes the computations and post hoc status.

Fresh40 runtime/call counts are checked by `scripts/check_saved_scores.py fresh40` against `studies/fresh40/run1/analysis/actual_costs.json` and the scoring ledgers. Model revisions and initial local freeze assets are checked for identity/integrity, not independently timestamped registration. The original missing raw checkpoints are disclosed in the main README and provenance guide.

Tables 1–10 and Figures 1–5 are in the main article. Tables S1–S12 and Figure S1 are in the standalone supplementary material. In the binding, the integer `number` field retains the 1–22 rendering order; `display_label` records the displayed main/supplementary numbering. The Overleaf project includes both source files and PDFs.
